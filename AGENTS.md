# elections26: election-night party invite (DiMax)

Live at https://elections26.dimaxtlv.com (GitHub Pages, noindex). A Hebrew RTL arcade-game invite: DiMax ident, INSERT VOTE, a threshold scene, character select, a fight, the poster, then victory, CONTINUE? and credits.

## Where things live
- **This repo is the published build.** The source lives on Max's Mac at `~/Documents/Vibe/TempConv/election-invite/`, outside this repo:
  - `final/`: page source, `copy.json`, `admin.html`, images and audio
  - `build_site.py`: builds into this repo
  - `gen_*.py`: fal.ai asset scripts
  - `analytics/`: the Cloudflare stats Worker
- `copy.json`: all text and game settings.
  - Text fields are option sets `[{t, on}]`; each run picks one of the options that are switched on.
  - It also holds the game rules (`game`), seats (`parties`) and the poll job's metadata (`polls_meta`).
  - Edit it from `/admin.html`. The PIN gate is light; saving needs Max's fine-grained GitHub token.
- `scripts/update_polls.py` + `.github/workflows/polls.yml`: the daily poll job (05:00 UTC, until 28.10).
  - Each polling company's latest poll from the last 21 days, plain average.
  - Commits `polls: daily update`.
- **Stats:** a Cloudflare Worker at `elections26-stats.dimaxtlv.workers.dev`, with a D1 table, on Max's personal Cloudflare account.
  - `/e` records events and `/idea` stores the free-text ideas from the box after the victory screen (production hostname only, capped at 10 per visitor and 500 in total per day).
  - `/count` is public (fights and wins).
  - `/stats` needs the `ADMIN_KEY` secret; it also returns the latest 300 ideas and every RSVP with its likelihood (guest analysis in the admin under סטטיסטיקה).
  - `/rsvp` is public for names only.

## Game flow (10.10)
- A run plays down to the last man standing: losers stay out (sessionStorage), and when one camp is empty the rest fight their own ("פריימריז").
- Then the secret boss, Sarah Netanyahu (`boss.js`, images in `img/boss/`, generated by `gen_boss.py`): fake ending → 3 acts → ballots decide. Knobs in `game.boss` (on, sarah_win %, affiliates for the allies); lines in copy `boss`. Netanyahu always loses to her.
- The boss fight is simulated, not scripted (Max): each exchange rolls attacker, move and damage; her bar emptying moves to the next form; backup is called when the hero drops under 30 HP (forced in act 3 if it never happened). Allies are 2 random of the 4 closest; Netanyahu, when drawn, betrays the caller and fights beside her. Endings: `beam`, `ballot`, `homer`, random, each with a win and a loss. Test hooks: `FORCE_END`, `FORCE_TEAM`, `__BZ`.
- Catchphrases: copy `catchphrase.<id>`, a bubble after the KO. Real voice clips (`audio/say_<id>.mp3`, cut from YouTube with yt-dlp, Max approved 10.10) exist for abbas, golan, liberman, sarah; the list is in `SFX` in index.html. Sources and trim points: `clips/raw/`.
- Hits: one sound per move kind (`hit_<kind>1|2`, `gen_hits.py`).
- Secret: tap the number between the health bars as many times as it shows; that fight's winner skips to the boss.
- Finishers: `finishers.js`, 3 per character, names in copy `moves.<id>` (same order).
- Fights are simulated hit by hit (`bout()` in index.html): each hit rolls its force from the party's poll range (`parties[].range`, lowest–highest poll, written by the daily job) × the list weight; up to +30% HP for the strongest. Knobs in `game.bout` (exp .3, spread .6, tier .5 gave Netanyahu–Abbas 90%, Eisenkot–Katz 81%). Fixed rates (`game.win`) still win.
- RSVP: Worker `/rsvp` (POST name + 0–100, one per visitor; GET names only). The board sits above the credits; the likelihood only shows in the admin stats.
- Satire guardrails for Sarah: documented events only, no body/age/children jokes, no sexualisation (she is a real person and sues).
